How to read this comparison

ROC-AUC measures ranking; average precision summarises the precision-recall curve for bad-credit outcomes. Log-loss and Brier evaluate probabilities. The constant baseline predicts the training bad-credit rate for every validation case.

AUC intervals and the difference between the two primary models use 1,000 paired, outcome-stratified bootstrap samples of validation rows. These are conditional on the fitted models, not estimates of all training uncertainty. Repeated decisions based on this validation set can overfit it.

Data are historical and bad credits were oversampled. Sample probabilities and calibration cannot be treated as current population default rates.

Decision policy

Accept if the bad-credit score is below the threshold. Costs are simulated.

Method and limits

The age cut-off is an analytical choice. Excluding age does not remove correlated proxies or guarantee fairness.

Intervals describe uncertainty in each subgroup rate conditional on the model and chosen threshold. They are not confidence intervals for a between-group difference and do not account for threshold selection. Small denominators make estimates imprecise. The dataset's combined personal-status variable cannot reliably reconstruct sex, so no male/female analysis is attempted.

Stability method

Training resamples are stratified by outcome. Preprocessing is refitted each time with a different model seed. Score SD is averaged across validation cases. Decision disagreement compares each refit with the original model. Twelve refits do not provide a confidence guarantee.

Reproduce the example

From the repository root, create a Python environment, install requirements.txt, then run python benchmark.py and python build_report.py. Open docs/index.html. It is self-contained and works offline. Fitted pipelines are saved locally in models/; public results contain validation predictions only.

Model settings: regularised logistic regression with C=1; Random Forest with 250 trees, minimum leaf size 5 and square-root feature sampling. No tuning of those settings was conducted.

Prototype using precomputed validation scores. No final model recommendation yet.
